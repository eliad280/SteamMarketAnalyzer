# Steam Market Analyzer

אפליקציית ווב מקומית לניתוח מחירי פריטים ב-Steam Community Market, המלצות מכירה, וסקירת שווי ה-Inventory שלך.

## התקנה והרצה

דרוש Python 3.11 ומעלה מותקן (ונגיש דרך `python` או ה-launcher `py`) - https://www.python.org/downloads/

**הדרך הנוחה - לחיצה כפולה:** לחץ פעמיים על `Run Steam Market Analyzer.bat`.

בהרצה הראשונה בלבד, הקובץ בונה לבד סביבה וירטואלית (`.venv`) ומתקין את כל התלויות מ-`requirements.txt` - זה עשוי לקחת דקה, ורואים את ההתקדמות בחלון שנפתח. מההרצה השנייה ואילך זה כבר לא קורה שוב, והאפליקציה נפתחת ישר בחלון אפליקציה נפרד (לא דפדפן, לא טרמינל) - וכשסוגרים את החלון, השרת נסגר לבד אוטומטית ברקע. אפשר ליצור קיצור דרך (Shortcut) לקובץ הזה על שולחן העבודה לנוחות.

זו גם הדרך המומלצת אחרי הורדת הפרויקט מ-GitHub - אין צורך להריץ שום פקודת התקנה ידנית.

**הדרך הידנית (למפתחים):**
```bash
cd C:\Users\eliad\Documents\SteamMarketAnalyzer
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
ואז פתח בדפדפן: http://localhost:8000 (כאן צריך לסגור את השרת ידנית עם Ctrl+C בטרמינל).

## תכונות

1. **ניתוח פריט בודד** — הזנת שם פריט מדויק ומשחק, קבלת מחיר נוכחי, המלצה (מכור / החזק / המתן) ותחזית מבוססת סטטיסטיקה (ממוצע נע, מגמה בריבועים פחותים, Z-score, נפח מסחר).
2. **בדיקת Inventory** — הזנת SteamID64 ומשחק, טעינת כל הפריטים, סינון לפי סוג פריט ולפי חיפוש חופשי, וחישוב שווי כולל של הפריטים המסוננים.
3. **מטבע** — מעבר בין USD ל-ILS מכל מסך.

## מגבלות חשובות שכדאי לדעת

- **הגנת אנטי-בוט של Steam (Akamai):** קריאות רגילות מקוד Python (גם עם headers שנראים כמו דפדפן) עלולות להיחסם עם שגיאת 429, כי Steam בודק גם את טביעת האצבע הטכנית (TLS/HTTP2) של החיבור, לא רק את ה-headers. האפליקציה משתמשת בספריית `curl_cffi` שמדמה בדיוק את טביעת האצבע של Chrome אמיתי כדי לעקוף את זה. אם אחרי כל זה עדיין מתקבל 429 שוב ושוב על אותה קריאה ספציפית - זה כנראה קירור זמני (cooldown) על ה-URL הספציפי הזה עקב בדיקות חוזרות, לא בעיה מהותית. עדיף להמתין כמה דקות ולא לרענן/ללחוץ שוב ושוב, כי זה רק מאריך את הזמן.
- **אין API רשמי וחינמי להיסטוריית מחירים.** Steam לא חושף היסטוריית מחירים לגולשים אנונימיים. לכן האפליקציה **בונה היסטוריה משלה** — כל פעם שאתה בודק פריט, המחיר נשמר מקומית ב-SQLite (`data/market.db`). ככל שתשתמש באפליקציה יותר לאורך זמן (ימים/שבועות), התחזית וההמלצה יהיו מדויקות יותר. בבדיקה ראשונה של פריט תקבל הודעה שאין עדיין מספיק נתונים.
- **אופציונלי — היסטוריה אמיתית מיידית (מומלץ):** בדיוק אותו גרף היסטוריית מחירים שרואים בדף פריט ב-Steam Market זמין דרך API של Steam, אבל רק למשתמשים מחוברים (לא אנונימיים) - זו הסיבה שהאפליקציה לא משתמשת בו כברירת מחדל. יש שתי דרכים להפעיל את זה, שתיהן שומרות את הפרטים ב-`config.json` בלבד (קובץ מקומי, לא נכנס ל-git):

  **דרך א' - כפתור בתוך האפליקציה (הכי נוח):** לחץ על "התחבר ל-Steam" בפינה הימנית העליונה של הממשק. זה בדיוק אותו מנגנון כמו `login_helper.py` (ראה תיאור למטה), רק שהוא מופעל ישירות מהאפליקציה בלי טרמינל.

  **דרך ב' - כלי התחברות עצמאי:**
  ```bash
  python login_helper.py
  ```
  ייפתח חלון אמיתי של דף ההתחברות של Steam (מבוסס Edge WebView2 - זהו steamcommunity.com האמיתי, לא חיקוי). מתחברים כרגיל, כולל Steam Guard אם נדרש. הסיסמה שלך מוקלדת ישירות לתוך העמוד האמיתי של Steam ולעולם לא נחשפת לאפליקציה - הסקריפט רק קורא את העוגיות (cookies) שנוצרות אחרי ההתחברות (בדיוק כמו שאפשר להעתיק ידנית מ-DevTools) ושומר אותן אוטומטית ב-`config.json`. החלון נסגר לבד ברגע שההתחברות זוהתה.

  **דרך ג' - העתקה ידנית:**
  1. התחבר ל-steamcommunity.com בדפדפן הרגיל שלך.
  2. פתח כלי פיתוח (F12) → Application/Storage → Cookies → `https://steamcommunity.com`.
  3. העתק את הערכים של `steamLoginSecure` ו-`sessionid`.
  4. העתק את `config.example.json` ל-`config.json` והדבק את שני הערכים בשדות המתאימים.

  לאחר מכן `/api/history` ו-`/api/predict` ישתמשו אוטומטית בהיסטוריה האמיתית והמלאה של Steam במקום להסתמך על צבירה עצמית. זה אופציונלי לגמרי והאפליקציה עובדת בלעדיו. **אלו פרטי ההתחברות שלך — הם נשמרים רק במחשב שלך, נשלחים רק ל-steamcommunity.com, ואסור לשתף את קובץ `config.json` עם אף אחד.** תוקף העוגייה מוגבל בזמן - אם ההיסטוריה מפסיקה להיטען, יש להריץ את `login_helper.py` שוב.
- **Inventory חייב להיות ציבורי** בהגדרות הפרטיות של Steam כדי שהאפליקציה תוכל לקרוא אותו.
- **הגבלות קצב (Rate Limiting):** Steam חוסם קריאות תכופות מדי לשוק. האפליקציה משהה כל קריאה במרווח קטן ושומרת מטמון (cache) ל-15 דקות, אבל בדיקת Inventory גדול עם הרבה פריטים ייחודיים עלולה לקחת זמן. מומלץ לסנן לפי סוג פריט או לחפש לפני לחיצה על "חשב שווי".
- **קוד המטבע ל-ILS (35)** נבדק ואומת מול ה-API בפועל. אם אי-פעם המחיר בשקלים ייראה שגוי, ניתן לתקן בקובץ `app/currency.py`.
- שם הפריט חייב להיות מדויק (`market_hash_name`) כפי שמופיע בכתובת ה-URL של דף הפריט ב-Steam Market.

## מבנה הפרויקט

```
app/
  main.py         - FastAPI, כל ה-endpoints
  steam_api.py    - קריאות ל-Steam (מחירים, Inventory, Rate limiting)
  prediction.py   - ניתוח סטטיסטי וההמלצה
  currency.py     - המרת מטבע ופענוח מחרוזות מחיר
  db.py           - SQLite: היסטוריית מחירים ומטמון
  static/         - הממשק (HTML/CSS/JS, ללא תלות חיצונית)
data/market.db    - נוצר אוטומטית, שומר את היסטוריית המחירים שנאספה
config.json       - אופציונלי, לא נדרש להרצה בסיסית
launch_app.py     - מפעיל את השרת ברקע + חלון אפליקציה, סוגר את השרת אוטומטית עם החלון
Run Steam Market Analyzer.bat - קיצור להרצת launch_app.py בלחיצה כפולה, כולל בניית הסביבה הווירטואלית אוטומטית בפעם הראשונה
login_helper.py   - כלי התחברות עצמאי ל-Steam (יש גם כפתור מקביל בתוך האפליקציה)
```
